# MSI Passport — El despertar de un Dragón

1. **Participación gratuita.** No es necesario realizar compras para acumular puntos ni para participar en la rifa.
2. **Registro único.** Cada participante se registra con nombre, teléfono y correo electrónico y recibe un identificador MSI Passport. Solo se permite una cuenta por persona.
3. **Acumulación de puntos.** Los puntos se obtienen mediante trivias, retos educativos, visitas a estaciones y misiones especiales, según la puntuación anunciada para cada actividad.
4. **Trivias.** Cada respuesta correcta otorga los puntos definidos para esa pregunta. Las respuestas incorrectas no restan puntos. Se permite un intento puntuable por trivia.
5. **Validación de misiones.** El personal autorizado de Digit@l Solutions valida las actividades presenciales y los códigos. Ingresar un código no garantiza puntos si no se cumplen las condiciones.
6. **Tabla de posiciones.** El ranking se ordena por puntos acumulados. Los cinco participantes con mayor puntuación son reconocidos como el Top 5 de MSI Passport.
7. **Desempates.** Se resuelven por mayor cantidad de respuestas correctas acumuladas; después, por número de eventos completados y, finalmente, mediante una pregunta de desempate supervisada.
8. **Participación en la rifa.** Cada participante registrado y elegible tiene una oportunidad en la rifa final, independientemente de sus puntos. El Top 5 es un reconocimiento separado y no aumenta las probabilidades de ganar.
9. **Conducta y transparencia.** Se prohíben cuentas duplicadas, manipulación de respuestas, intercambio indebido de códigos o cualquier intento de alterar la puntuación. Las incidencias se documentan y revisan antes de aplicar una descalificación.
10. **Cierre de puntuaciones.** El 11 de diciembre se realiza la última trivia. Al finalizar el período anunciado se bloquean nuevas puntuaciones, se revisan incidencias y se publica el Top 5 definitivo.
11. **Premiación y rifa.** El equipo MSI se sortea mediante un procedimiento aleatorio y verificable entre los participantes elegibles. La fecha, el lugar, las condiciones de entrega y el procedimiento de reclamación se comunican previamente.
12. **Protección de datos.** Los datos personales se usan para administrar la campaña y contactar a los ganadores. Las comunicaciones comerciales requieren consentimiento separado. El ranking público muestra únicamente alias e identificadores parciales.
